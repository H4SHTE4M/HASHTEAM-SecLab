进门

一行命令，一次请求

whoami你是谁？ → guest
pwd我在哪？ → /home/guest
ls这里有什么？ → README
怎么读左边是请求，右边是电脑返回的结果。

终端就是这样：你请求，它响应。

关卡对应：SecLab 第 1 关「欢迎来到服务器」；whoami、pwd、ls 和读取 README 都在这一关。

【3:00–6:00】三条命令玩过 lab 的都敲过；没玩过的现在看懂就行。

「请求/响应」是计算机自己的词，后面讲服务时会直接升级成 HTTP 请求；口头对比一句「就像直接点菜」接上一页。

01 / 04　看见 问文件

ls 默认不显示以「.」开头的条目

guest@hashteam — 实验环境

ls

notes.txt

ls -a

.　..　.message　.profile　notes.txt

为什么ls 默认省略以「.」开头的条目；-a 要求显示全部。

参数是对请求的额外要求。

关卡对应：SecLab 第 2 关「消失的文件」；核心动作是用 ls -a 找到 .message。

【6:00–8:30】玩过的同学记得 .message。这句是开场那句话的第一次回收：ls -a 就是「单点」。

以「.」开头是 Unix-like 系统的隐藏条目约定；不要类比手机隐藏相册，不是同一种机制。

可能被问：.profile 是系统自己的配置文件，和今天无关；. 和 .. 是每个目录都有的特殊条目（lab 第 2 关会专门讲）。

过渡：文件能问，那看不懂的内容呢？

Base64 是编码，不是加密

guest@hashteam — 实验环境

……
这是第一块碎片：nebula
另一半碎片藏在一个二进制文件里……

发生了什么-d 表示 decode：把 Base64 表示还原成原始内容。
编码≠加密

关卡对应：SecLab 第 7 关「看不懂的消息」；message.b64、Base64 解码和拼接碎片都在这一关。

【8:30–11:00】一条命令，乱码变中文。base64 是可逆编码，不提供保密性；日记倒着写是编码，锁进保险箱才更像加密。这里要讲清楚，不然学生容易把「看不懂」当成「被保护」。

过渡：文件能问，内容能问——电脑还记得的事，也能问。

04 / 04　走出去 再问一个公开路径

关键robots.txt 是给爬虫的收录规则，不是权限控制；敏感路径不该靠它隐藏。

关卡对应：SecLab 第 9 关「被遗忘的调试接口」；robots.txt 是首页之后的公开路径线索。

【21:00–23:00】先读屏幕上的授权边界，再演示。robots.txt 是站点给爬虫的规则文件，不是访问控制，也不应拿来存放敏感路径。

嘴上带一句「这页等于在菜单上写着『请勿拍照』，但单点照样能点」——点到为止，这页信息已经满了。

这里的文件是实验环境主动设计的线索。真实网站即使某个路径公开可访问，也不代表你获得了继续探测、绕过控制或使用其中信息的授权。
